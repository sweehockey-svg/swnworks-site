# Cockpit usage admin

Entry: `/commentator-cockpit/admin/`. Requires an active global `commentator_access` admin (no team/league scope). This is NOT granted merely by having an Auth account. Server verifies the user token with `getUser()` and rechecks the access table on every request.

Apply `supabase/commentator_usage.sql` once to hockey-commentator (`pqaymcvlwsruxvekvvtl`), then deploy `supabase/functions/commentator-usage/index.ts` as `commentator-usage` with JWT verification enabled. pg_cron is already enabled on this project. The service-only RPCs use invoker rights; limited column grants expose only user/login metadata to service_role, not password or token columns. RLS plus revoked client privileges prohibit direct client read/write. Client events cannot choose their owner or event timestamp. Recording is bounded and deduplicated per user inside a transaction lock.

Frontend: `usage.js` is attached to the existing authenticated client on the league selector and all three league pages; feature hooks live in the shared Hockeyettan cockpit. It sends page/feature/player-card opens and approximate visible, recently-interacted active minutes. No form data, free text, notes, search strings, IP, full URL, user agent or credentials are stored in usage events. A visible signed-in notice explains scope, 90-day retention, admin visibility and contact. Normal site reads are unaffected if measurement fails.

Admin report: account metadata, surviving auth sessions, usage counts, the latest 500 events and sessions, function totals, and existing saved-content COUNTS only. Never note titles/bodies or AI prompts. Usage filters are 7/30/90 days and person. Existing content counts are all-time and explicitly labeled. Activity is not evidence of exact time worked. Missing events do not establish non-use. Refresh tokens do not count as new logins. The auth session history is incomplete if sessions were removed. Older activity cannot be reconstructed. Historical notes/AI/lineup rows are not converted into fake view events.

Daily `commentator-usage-retention` cron removes usage events older than 90 days. It does not delete original notes, AI metadata or auth sessions. Tracking starts at publication; public/anonymous visitors are not measured. No report data is saved in browser storage. Log out to clear rendered personal data. Do not expose the service key or add public RPC execution grants.
